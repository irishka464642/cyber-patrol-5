# 🛡️ Кіберпатруль — інтерактивний квест для 5 класу

Навчальна гра до уроку **«Спілкування в інтернеті. Етикет спілкування в мережі. Безпечне використання інтернету»** (10.11.2026, 5-Б клас).

## Місії
1. 💬 Чат під контролем — правила мережевого етикету.
2. 🧠 Що відповіси? — безпечна комунікація.
3. 🎣 Розпізнай пастку — фішингові повідомлення та файли.
4. 🔒 Мої дані — приватність і паролі.
5. 🏅 Фінальний виклик — застосування правил у складніших ситуаціях.

15 запитань, 1 бал за кожну правильну відповідь із першої спроби, пояснення після кожного вибору. Результати **не передаються й не зберігаються на сервері**.

## Як опублікувати на GitHub Pages
1. Відкрити **Settings → Pages** у репозиторії.
2. У розділі **Build and deployment → Source** вибрати **Deploy from a branch**.
3. Вибрати **main** і **/(root)**, натиснути **Save**.
4. Після публікації сторінка має бути доступна за адресою **https://irishka464642.github.io/cyber-patrol-5/**.

## Використання на уроці
Учні можуть працювати самостійно або в парах. Орієнтовно 15–20 хвилин. Після проходження обговоріть, чому певні відповіді були небезпечними. Для повторення натисніть **«Пройти ще раз»**.

## Технічно
Застосунок — один файл `index.html`, HTML + CSS + JavaScript без сторонніх залежностей, адаптивний до телефонів та комп'ютерів. Працює без акаунтів і без аналітики.
